# Security policy

This forum holds personal data about its members, so security reports are welcome and taken
seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/veekbee/something_forum/security/advisories/new)
rather than in a public issue. Include steps to reproduce and the impact you expect.

You can expect an acknowledgement within a few days. Please give us a reasonable time to fix the
issue before disclosing it.

## Scope

The code in this repository. The deployed forum is closed to the public; do not attempt to access
it or its members' data.
