# Fonts

Unmodified variable WOFF2 files from Adobe's official releases, served from the site itself
(docs/DESIGN.md, Visual design; rule 73). Each is licensed under the SIL Open Font License 1.1;
the licence is in `OFL.txt` beside the files. "Source" is a Reserved Font Name: the files are not
subset or otherwise modified, so the name may stay.

- `source-serif-4/`: Source Serif 4, release 4.005R (github.com/adobe-fonts/source-serif)
- `source-sans-3/`: Source Sans 3, release 3.052R (github.com/adobe-fonts/source-sans)
